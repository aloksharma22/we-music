# We Music 🎵

A modern, community-driven music streaming web application with collaborative listening rooms, offline playback, and real-time community engagement.

🔗 **Live Demo**: [https://we-music-flame.vercel.app/](https://we-music-flame.vercel.app/)

---

## Features

- **Direct High-Fidelity Audio**: 380+ curated songs including Coke Studio essentials, Anuv Jain, FIFA anthems, and indie classics.
- **Collaborative Listening Rooms**: Listen together with friends in synchronized rooms with real-time text chat.
- **Offline Caching**: Cache tracks directly in your browser for playback without an internet connection.
- **Custom Playlists**: Create, edit, and organize custom playlists with ease.
- **Song Comments**: Leave timestamped comments and join discussions on any track.
- **Artist Live Studio**: Audio frequency visualizer and interactive playback stage.
- **Theme Support**: Seamless switching between Light, Dark Studio, and Deep OLED modes.

---

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons
- **Audio**: HTML5 Audio & Web Audio API
- **Deployment**: Vercel
